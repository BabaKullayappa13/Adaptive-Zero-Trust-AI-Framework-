🚀 QUICKEST PATH (3 STEPS)
═══════════════════════════════════════════════════════════════════════════

STEP 1: RUN SETUP SCRIPT
─────────────────────────
Open PowerShell and run:

  Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
  .\setup-windows.ps1

This will automatically:
  ✓ Check Node.js (npm)
  ✓ Check Python
  ✓ Install frontend dependencies
  ✓ Setup Python environment
  ✓ Install backend dependencies
  ✓ Create configuration files

(If this doesn't work, run: setup-windows.bat instead)


STEP 2: CREATE DATABASE
────────────────────────
Open PowerShell and run:

  psql -U postgres

Then run these SQL commands:

  CREATE DATABASE zero_trust_ai;
  CREATE USER zero_trust_user WITH PASSWORD 'password123';
  GRANT ALL PRIVILEGES ON DATABASE zero_trust_ai TO zero_trust_user;
  \q

Then update backend/.env:
  DATABASE_URL=postgresql://zero_trust_user:password123@localhost:5432/zero_trust_ai
  JWT_SECRET_KEY=your-secret-key-at-least-32-characters
  FASTAPI_ENV=development


STEP 3: START SERVICES
───────────────────────
Terminal 1 (Backend):
  cd backend
  .\venv\Scripts\Activate.ps1
  uvicorn main:app --reload

Terminal 2 (Frontend):
  cd frontend
  npm run dev

Then open: http://localhost:3000

❓ COMMON QUESTIONS
═══════════════════════════════════════════════════════════════════════════

Q: What if npm/Python still isn't recognized?
A: Restart your computer! PATH changes take effect after restart.

Q: What if setup script doesn't work?
A: Run verify-setup.bat to check what's missing.
   Then read WINDOWS_QUICK_START.md for manual steps.

Q: How do I know setup worked?
A: Run: .\verify-setup.bat
   Should show all ✓ checks passing.

Q: What if I get a port already in use error?
A: Another service is using that port.
   See "Troubleshooting" in WINDOWS_README.md

Q: Can I use Command Prompt instead of PowerShell?
A: Yes! Use setup-windows.bat instead of setup-windows.ps1

Q: Do I need to install anything else?
A: Only if setup script fails. Check WINDOWS_SETUP.md prerequisites.


⚠️ IF SOMETHING DOESN'T WORK
═══════════════════════════════════════════════════════════════════════════

1. Run verification:
   .\verify-setup.bat

2. Read troubleshooting:
   WINDOWS_README.md (Troubleshooting section)
   or
   WINDOWS_QUICK_START.md (Common Issues section)

3. Check prerequisites installed:
   node --version          (should show v20.x.x)
   npm --version           (should show 10.x.x)
   python --version        (should show 3.11.x or later)
   psql --version          (should show PostgreSQL)

4. If still stuck, try manual setup:
   Read: WINDOWS_SETUP.md (detailed step-by-step)
