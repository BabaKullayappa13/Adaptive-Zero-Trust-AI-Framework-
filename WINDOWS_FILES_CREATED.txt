1. CREATE DATABASE

   psql -U postgres

   CREATE DATABASE zero_trust_ai;

   ──────────────────

   NEXT_PUBLIC_API_URL=http://localhost:8000

                          TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════════

"npm is not recognized"
→ Restart PowerShell completely
→ Restart your computer
→ Check Node.js installed: where npm

"python is not found"
→ Uninstall Python completely
→ Reinstall, checking "Add to PATH"
→ Restart computer

"Port 8000 already in use"
→ netstat -ano | findstr :8000
→ taskkill /PID <number> /F
→ Or use different port: uvicorn main:app --reload --port 8001

"Cannot install dependencies"
→ pip cache purge
→ pip install -r requirements.txt

"Frontend won't connect"
→ Make sure backend is running on :8000
→ Check .env files have correct URLs
→ Restart frontend
